## 📌 Descrição do Projeto
Aplicação interativa em C11 que implementa uma **Árvore Binária de Busca (BST)** para gerenciamento de livros (indexados por ID positivo único) e uma **Pilha Encadeada Dinâmica** como estrutura linear auxiliar independente.

---

## 🛠️ Como Compilar e Executar

### Pré-requisitos:
- Compilador GCC instalado (suporte a C11).
- Utilitário `make` (ou `mingw32-make` no Windows).

### Comandos de Compilação:
No terminal da raiz do projeto, execute:
